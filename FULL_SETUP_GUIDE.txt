❓ TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

Vấn đề: "Python not found"
Giải pháp:
  - Đảm bảo Python được cài đặt
  - Thêm Python vào PATH
  - Hoặc sử dụng đường dẫn đầy đủ: C:\...\python.exe

Vấn đề: "pip: command not found"
Giải pháp:
  - Chạy: python -m ensurepip --upgrade
  - Hoặc: python -m pip install -r requirements.txt

Vấn đề: "ModuleNotFoundError: No module named 'openai'"
Giải pháp:
  - Chạy: pip install -r requirements.txt
  - Kiểm tra: pip list | grep openai

Vấn đề: "Node.js modules not working"
Giải pháp:
  - Đảm bảo npm được cài đặt: npm --version
  - Reinstall: rm -r node_modules && npm install
  - Hoặc: npm ci (sử dụng package-lock.json)
